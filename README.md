# ExamSphere — Online Examination System

An Android Java project for conducting timed online examinations.

## Features
- Local user authentication/session
- Dashboard with exam cards
- RecyclerView-based dynamic exam listing
- Exam search/filter
- Multiple-choice questions
- Countdown timer and automatic submission
- Score/result screen
- Logout functionality
- Material-style responsive UI

## Tech Stack
- Java
- Android SDK
- XML layouts
- RecyclerView
- Material Components
- SharedPreferences

## Run
1. Open the `OnlineExaminationSystem` folder in Android Studio.
2. Let Gradle sync.
3. Select an emulator or Android device.
4. Run the `app` module.
